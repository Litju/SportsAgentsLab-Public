# How it works

The public example follows a bounded path:

1. A synthetic force-platform recording is represented with time in seconds and
   vertical force in newtons.
2. Input checks confirm finite values, monotonic time, and explicit units.
3. Deterministic helpers integrate acceleration and derive an illustrative
   flight-time height estimate.
4. A quality summary separates calculation output from review notes.
5. Agent interfaces carry structured results to a practitioner-facing surface.

The showcase is deliberately offline. It calls no service, needs no model key,
and contains no athlete record.
