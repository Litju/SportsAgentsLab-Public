# Scientific approach

Numerical code is small, explicit, and unit-labeled. The illustrative CMJ
vertical slice uses a deterministic synthetic trace and a trapezoidal integral;
it is an example of computation and provenance, not a universal measurement
claim.

Readers should distinguish:

- construction truth: values chosen by the synthetic generator;
- derived calculation: values produced by the public helper;
- review note: a human-readable limitation or quality observation;
- uncertainty: what the example does not establish.

The example does not encode hidden event rules, device mappings, or an
evaluation corpus. New scientific behavior should be added as a versioned,
reviewed public example rather than silently changing an existing result.
