# ML-105 Scientific Boundary Proof

ML-105 resolves acquisition configuration and evidence status only. The pure package has no Next.js, Vercel, Neon, authentication, Blob, LLM, biomechanics, CMJ, or scientific-analysis dependency. It does not compute force-time features, jumps, thresholds, body-mass normalization, event detection, or scientific conclusions.

Declared preprocessing metadata is preserved as configuration evidence; it is not applied to raw signals. Unknown and unsupported states remain explicit. No ML-106 implementation was started, and no CMJ or biomechanics field was added to the ML-105 contract.

```text
CMJ_SCIENCE_IMPLEMENTED=NO
SCIENTIFIC_LEAKAGE=NONE
RAW_REPARSE_OR_CANONICALIZATION=NO
```
