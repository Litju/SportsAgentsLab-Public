# Measurement Agent

**Question:** What was measured?

The Measurement Agent organizes measurement-system data, scientific
processing, quality review, provenance, and practitioner evidence. The public
CMJ example shows a synthetic force-platform recording, a deterministic
calculation, and a readable limitation note.

The public boundary intentionally does not expose private event thresholds,
device mappings, or internal processing names. Future public examples may
cover more force-platform tests, velocity-based training, GNSS/tracking,
inertial measurement, and timing.
