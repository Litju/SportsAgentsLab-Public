# Privacy and safety

The showcase uses synthetic data only. It contains no athlete identifiers,
raw recordings, account data, credentials, private service calls, or customer
integrations.

The public repository is source-available and proprietary. Public visibility is
not a grant to reuse the code, data, diagrams, or documentation. The private
product remains the authority; this repository is a non-authoritative snapshot.

Scientific examples state their scope and limitations. A practitioner must
review evidence and context before making a training decision.
